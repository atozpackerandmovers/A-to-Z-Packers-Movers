# Daily vehicle inspection

Driver submissions already save to `azpExecutionRecords`, module `fleetDailyInspection`.
Office opens Execution → Daily Inspection / दैनिक जाँच, or Fleet Management → Daily Inspection.
Full checklist, evidence link, driver faults and action are shown. Office records
Approved, Repair Required, Vehicle Hold or Rejected, with reviewer and instruction.
A transaction updates only review fields in the original collection; it rejects
reviews of changed submissions. Driver history displays office status and note.
Driver resubmission resets the decision to Pending and clears the earlier note.
No existing report is imported, duplicated or approved automatically.
