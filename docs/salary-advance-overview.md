# Salary advance and overview

Office: Attendance → employee → Salary Overview → Edit Salary / Record Total Advance.
The same record is available in Salary Final Approval. Total Already Paid / Advance
is cumulative for the current unpaid period: after INR 2,000 plus INR 1,000, enter
INR 3,000. A blank field preserves saved credit; explicit zero clears it. Pending
status no longer erases a positive entered credit. Salary amounts are saved in
azpExecutionRecords / salaryFinalApproval with the current payment policy and cycle.

Overview shows fiscal year, current unpaid period, payable days, earnings breakdown,
deductions, net before payments, payments/advance and remaining due. Driver Salary
uses the same overview for canonical saved salary. Reference screenshot amounts
are not inserted into employee accounts. Historical Salary/payroll advances are
not automatically imported: verification is needed to avoid counting twice.
